
# Portfolio

A modern, production-grade developer portfolio designed to showcase my software engineering journey.

Rather than being a static résumé, this project is built as a living engineering dashboard that automatically highlights my latest projects, GitHub activity, technical writing, and continuous learning.

## Features

- 🚀 Modern responsive design
- 📱 Mobile-first experience
- 💻 Live GitHub integration
- 📂 Dynamic project case studies
- 📝 MDX-powered blog
- 🧩 Algorithm library
- 📊 Engineering dashboard
- ⚡ Optimized performance
- ♿ Accessibility-first
- 🔍 SEO optimized

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion
- MDX
- GitHub GraphQL API
- Vercel

🚧 Currently under active development.
